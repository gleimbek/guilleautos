# Guille Autos

Website proposal for Guille Autos, a car dealership in Argentina. In Spanish.

**Live site:** https://gleimbek.github.io/guilleautos/

## What it has

- **Available cars** with photos of the dealership's real vehicles
- **Photo gallery** that opens each image in a larger view
- **Contact form** that checks every field, then writes the message and opens it in WhatsApp, addressed to the dealership

## Built with

HTML, CSS and vanilla JavaScript, no frameworks or build step.

## Run locally

Open `index.html` in a browser.
